# Roadmap

- M0 develops the desktop shell, bounded queue, simulation adapter, local theme persistence, Windows CI and portable packaging.
- M1 validates the first real adapter, content detection, atomic output publication and recoverable failure handling.
- Subsequent milestones add video, audio, images, PDF, Office, archive, structured data and e-books according to adapter readiness and release review.
- Distribution milestones validate Windows installers and review macOS and Linux packages and platform-specific isolation.
